# Planning

## Product

Cyber Prospect Intelligence is a lightweight sales-intelligence application
for cybersecurity teams.

## Problem

Security sales teams may have large amounts of internet-facing infrastructure
data but need a faster way to identify organizations worth researching.

## Chosen Use Cases

### 1. Prospect prioritization

Rank observable infrastructure records using deterministic signals.

### 2. Prospect investigation

Show the evidence behind an individual prospect score.

### 3. Sales research assistance

Generate a concise explanation and research question from observed signals.

## Why These Use Cases

They demonstrate a complete workflow from raw data to an actionable sales
research experience without requiring unsupported assumptions about a company's
security posture.

## MVP Scope

- Dataset sampling
- Data normalization
- Signal extraction
- Explainable scoring
- Prospect filtering
- Prospect detail view
- AI-assisted evidence summaries
- Evaluation dataset
